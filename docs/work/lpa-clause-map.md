# LPA 条款图谱：有限合伙协议交互式知识地图

LPA 条款图谱是一款面向私募基金入门者和法律从业者的交互式阅读、审阅与起草辅助工具。它不按合同文字顺序机械展示内容，而是沿基金设立、募集、投资、管理、分配、退出和清算的生命周期重新组织条款关系。

[在线体验 →](https://hellyai.github.io/lpa-clause-map/) · [查看 GitHub 仓库 →](https://github.com/Hellyai/lpa-clause-map)

## 它解决什么问题

有限合伙协议通常篇幅很长，且条款之间存在大量交叉引用。初次接触时，读者容易看见单个条款，却难以理解它在基金整体机制中的位置，以及相关权利义务如何互相影响。

## 核心体验

- 将 LPA 拆分为 38 个结构化篇章；
- 每项条款分别展示基本规则、审核要点、常见分歧、起草落点和规则依据；
- 支持搜索管理费、收益分配、后续募集、关键人士、回拨等主题；
- 可以按基金生命周期模块筛选内容；
- 法规按钮跳转公开权威来源，便于核对原文；
- 支持个人批注，并能集中回看或导出 Markdown。

## 内容范围

项目覆盖基金设立与期限、合伙人及出资、后续募集、违约处理、管理人与治理、投资范围和限制、管理费与费用、收益分配与回拨、入伙退伙和权益转让、信息披露、托管、反洗钱、关键人士、解散与清算等核心主题。

## 我的设计判断

法律知识产品不应只把纸面目录搬到网页上。条款需要同时回答四个问题：它解决什么问题、审阅时争议在哪里、起草应落到哪里、依据能否被核验。交互设计则应帮助读者从整体结构进入细节，并保留自己的阅读痕迹。

## 隐私与更新边界

批注只保存在当前浏览器本地，不会上传到 GitHub。项目内容更新基准日为 **2026 年 7 月 31 日**；法规、自律规则和地方登记口径可能变化，使用时仍应核验最新规定。本工具属于学习、审阅和起草辅助材料，不构成针对具体基金的法律意见。
