# 交易法律 Skills：VC/PE 投资文件审阅助手

这是我把交易律师的审阅方法转化为 AI Agent 工作流的一次实践。项目不是一条“万能审合同”提示词，而是通过路由规则、专项审查清单、计算脚本和质量控制，把投资文件审阅拆解成可以执行和复核的步骤。

[查看 GitHub 仓库 →](https://github.com/Hellyai/transaction-legal-skills-)

## 它解决什么问题

VC/PE 交易文件往往互相引用，同一权利还会分散在 Term Sheet、投资协议、股东协议和公司章程中。单纯逐条摘要容易遗漏文件之间的冲突，也无法体现不同委托方的审阅立场。

这个 Skill 首先识别文件类型和我方身份，再进入对应的审阅路径：新进投资人、既有投资人、政府引导基金或产业投资人的关注点并不相同。

## 核心能力

- 自动区分 TS、投资协议、股东协议及交割文件；
- 对回购、反稀释、优先清算、MFN、共同出售、拖售等经济权利进行结构化审阅；
- 核查董事席位、保护性条款等治理安排；
- 输出 P0 / P1 / P2 风险级别、处理标签、修改建议与待核实事项；
- 对估值、注册资本、投资单价、ESOP 和反稀释事项提示专项 Cap Table 核验。

## 作品结构

项目包含总入口 `SKILL.md`、审阅路由、不同文件与投资人身份的参考规则、经济权利和治理专项规则、交割终检、输出模板、质量控制，以及用于权利计算的 Python 脚本。

## 我的设计判断

法律 AI 的价值不在于更快地产生一份长报告，而在于建立边界：先确认立场，完整读取材料，区分事实与推断，对关键数字做专项复核，并给专业人士留下明确的接管点。

## 隐私与适用边界

仓库只保留通用 SOP、模板、规则与计算脚本，不包含客户文件或项目信息。Skill 的输出用于辅助审阅，不构成正式法律意见；具体判断仍需结合完整交易文件、尽职调查、最新规则和执业律师复核。
