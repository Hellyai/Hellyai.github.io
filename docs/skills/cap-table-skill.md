# Cap Table Skill：融资股权结构计算与复核

这是一个面向融资交易的股权结构计算 Skill。它把注册资本、持股比例、投资价格和反摊薄条款转化为可追踪的计算过程，用于构建、复核和审计 Cap Table。

[查看 GitHub 仓库 →](https://github.com/Hellyai/cap-table-skill)

## 它解决什么问题

融资股权表的难点不只是“算出一个比例”，而是确认每一个数字采用了正确口径：新股和老股是否被混淆、OS 取值时点是否正确、多轮触发是否承接了上一轮完整精度，以及协议中受保护的股份范围是否与计算一致。

## 核心能力

- 普通增资、股权转让及投后股权结构计算；
- 新股与老股混合交易拆分；
- 多轮融资和连续反摊薄计算；
- 按协议核对 OCP、OS、NP、NS 及补偿数量；
- 股东、投资轮次和最终持股比例勾稽检查。

## 关键计算口径

同一次触发发行对不同受保护轮次使用相同的发行前 OS，但分别使用各自 OCP；老股转让数量和价款不计入 NS、NP；连续融资承接上一轮完整精度的调整后价格，并在每轮使用实际发行前 OS。

## 我的设计判断

交易计算应当可以回溯。相比只展示最终百分比，我更关注每轮的输入、公式、增量补偿和最终累计权益能否互相勾稽，使律师、投资人和财务人员可以定位差异来自哪里。

## 适用边界

具体计算以已经签署或正在审阅的投资协议、股东协议及完整交易文件为准。仓库不包含客户或项目数据，输出不能替代对协议文本和交易事实的人工核验。
